# Ivideon · Карта сокровищ

Корпоративная игра достижений, азарта и командных открытий — внутренняя площадка геймификации результатов.

Победа в рабочем периоде даёт право открыть один сектор карты. В секторе может ничего не оказаться, может найтись фрагмент сокровища или неожиданная находка. Основная награда открывается только после полного обнаружения сокровища — поэтому одной победы недостаточно, и конкуренция сохраняется на протяжении всей игры.

## Состав

- `index.html` — публичное табло активных игр;
- `admin.html` — единый вход, панель администратора и Owner;
- `editor.html` — редактор выбранной игры;
- `config.js` — публичная конфигурация Supabase (URL и publishable-ключ);
- `.nojekyll` — отключает обработку Jekyll на GitHub Pages;
- `supabase/` — необязательное обновление публичного снимка (см. `supabase/README.md`).

## Дизайн

Интерфейс построен по дизайн-системе **Corporate Treasure**: корпоративный
интерфейс Ivideon с дозированным тематическим слоем карты сокровищ.
Все цвета, отступы, скругления и шрифтовая шкала вынесены в CSS custom properties
(`--iv-blue`, `--parchment`, `--gold`, `--radius-*`, `--font-*`).

Пергамент используется только в карте и игровых элементах, золото — только для
ценности и наград, фирменный синий — для действий и навигации. Рабочие панели
остаются белыми. Все иконки — собственные inline SVG (линейные, stroke 1.8,
скруглённые концы); внешних изображений и stock-ресурсов нет.

Данные хранятся в Supabase: Auth, Postgres с RLS, Realtime и Edge Function `platform-admin`. Локального режима нет — источником истины остаётся Supabase.

## Разделы редактора

1. **Карта и сокровища** — участники, размещение сокровищ и находок, названия, награды, запечатывание карты.
2. **Открытие сектора** — выбор сценария, период оценки, показатели, подтверждение победителя и само открытие.
3. **Статистика** — открывается первой, чтобы случайно не показать размещение сокровищ.
4. **История исследований** — хронология открытий, журнал находок, отпечаток карты, снимки и восстановление.
5. **Расписание и критерии** — конструктор показателей и сценарии открытия сектора.
6. **Управление игрой** — статус, публичная ссылка, экспорт, сброс и корзина.

## Сценарии открытия сектора

Сценариев может быть сколько угодно. День проведения (каждый день, выбранные дни недели, только понедельник, Пн/Ср/Пт, раз в неделю, раз в месяц, конкретная дата, ручное событие) настраивается независимо от периода оценки (предыдущий день, предыдущий рабочий день, предыдущие N дней, выбранные дни недели, предыдущая неделя, текущая неделя до события, предыдущий месяц, фиксированный или ручной диапазон).

Показателям внутри сценария назначается роль: допуск, основной критерий, критерий при равенстве или только статистика. Победителя в любом случае подтверждает администратор. Обычная победа периода даёт одно открытие сектора; дополнительное открытие возможно только как эффект неожиданной находки.

Кнопка **«Готовый шаблон Пн / Ср / Пт»** создаёт три редактируемых сценария — это стартовая заготовка, а не обязательная схема.

## Проведение открытия

Открытие сектора — кульминация игрового периода, а не незаметное действие в личном кабинете. Команда собирается на встрече или созвоне, администратор объявляет результаты и победителя, победитель вслух называет сектор, администратор открывает его при всех, и результат появляется на публичном табло.

Инструкция доступна внутри панели и редактора по кнопке **«? Инструкция»**.
